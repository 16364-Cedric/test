Équiper un salarié

À scanner avec l'appareil photo du téléphone du salarié, après avoir installé l'application DATI. Le téléphone demande confirmation avant d'appliquer la configuration.

Ce QR code contient la clé secrète de l'appareil : il n'est affiché qu'une seule fois. Ne le diffusez pas.

Si le téléphone ne propose pas d'ouvrir le lien, copiez le lien ci-dessous dans DATI → Réglages → « Lien de configuration ».
